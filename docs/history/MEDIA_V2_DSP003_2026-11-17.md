## Changed and decisions

- Optional x64 native broker C API and per-plugin resident client. Protected local message pipe, exclusive server, owner SID/kernel client PID checks, exact build/config/endpoint/UUID/stream/connection/sequence fences. Fixed16peer/config slots, <=1KiB frames, one pending/in-flight packet,2–3s deadlines and joined event-driven teardown. IPC/control coefficient work remains outside the audio callback.
- Dispatch selection publishes its latest peer status and busy fence under the same mutex before I/O. Deterministically held A→B→A regression prevents cached A completion while B is reserved. Test hooks are absent from the ordinary DLL; held-dispatch shutdown is bounded.
- Resident worker never calls the host or changes host-owned effect delay. Safe host-owned dispatch points deliver pending IO_CHANGED last, outside locks; GET_CHUNK/suspend-to-stop/destroy do not. Actual worker regression synchronously destroys from the host callback without self-join/UAF; borrowed GET_CHUNK remains valid.
- Protocol3: Parameters72 (native preamp−24..+12dB), Bootstrap360, Status232, PeerReport320. Immutable whole settings, 20ms preamp ramp, random instance IDs, stream epochs, fingerprints, callback age tracked by the non-audio consumer and host-latency-pending telemetry. Pipe liveness alone cannot establish ongoing audio callbacks.
- DLL loading/declarations live in `core/utils/win32/bindings/yasb_media_dsp.py`, as upstream requires. Existing compiled ABI probe includes the actual project protocol/transport headers and hashes them into cache identity. All six C export signatures receive the same ABI checks; no SDK skip/exception was added.
- `apo.processor=graphic_eq|native`, defaultgraphic_eq, with explicit native_library/native_sha256. Existing GraphicEQ renderer/default behavior is byte-identical and starts no broker. Missing/incompatible native artifacts remain unavailable, never silently fall back.
- Existing canonical-file writer owns both routes, whole Audio+EQ intent, draft lease, latest coalescing, persistence and output retarget. Audio edits use committed EQ; Apply keeps latest Audio. Conflicting profiles/processors cannot claim a draft. Profile identity is frozen for the controller lease. Native float32 persisted-value comparisons include Audio, independently of DSP acknowledgements.
- Native state is atomic and selected-profile-bound, with first record backup; migration preserves the previous managed leaf. Stable bootstrap prevents watched APO rewrites on normal controls. Route file contains the plugin only, scoped L/R, with preamp exactly once. Endpoint changes/repair rewrite bootstrap; static rollback is exclusive and recoverable. Startup restoration is an authoritative-base barrier even after failure; Apply retries restoration. Obsolete routes retire their broker threads/handles on the serialized worker.
