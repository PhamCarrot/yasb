## Change and preservation

It clears per-attempt stock/external-filter diagnostics and invalidates the per-manager payload cache when the discovered installation changes, before parent validation can fail. It then uses the captured installation for that attempt. Missing/duplicated/incomplete markers, permission failures and existing backup/custom-config rules retain their conservative behavior.
