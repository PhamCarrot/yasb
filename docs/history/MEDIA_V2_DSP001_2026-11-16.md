## Change and scope

Optional native C++17/static-CRT x64 DLL implements ten Q=1 peaking filters,
20ms coefficient/stereo ramps, mono, swap and linear balance (inactive in mono).
Coefficient preparation is non-audio. Fixed three-slot SPSC mailboxes coalesce
parameters and reports; non-audio producers/readers serialize through one owner.
The callback has no filesystem/IPC/heap/locking operations. Accepted/applied/
settled revisions, source build ID, process instance, sample rate and frame counts
are distinct. Full-state validation rejects unknown/nonfinite/stale commands.

Six explicitly supported rates:44.1/48/88.2/96/176.4/192kHz, stereo float32.
Unsupported formats bypass and report unsupported. Host must stop **and drain**
processing before format changes/destruction. Setting suspended alone does not
join in-flight callbacks. Independent native host loads actual exported ABI;
both replacing and legacy accumulating entrypoints are exercised.

`build_media_dsp.py` reuses existing MSVC discovery; output defaults under `.git`.
Binary is optional, not loaded or packaged in normal YASB yet. Build emits source/
DLL hashes, build ID and notices. Current proof build ID`709393a9e81d3f0e`.
Native [README](../../src/core/widgets/services/media/native/README.md) records
supported scope/lifecycle/provenance. Raw pinned BSD interoperability header,
LICENSE and README are preserved and copied beside binary builds. W3C peaking
mathematics is independently implemented; no AGPL engine code/assets translated.
