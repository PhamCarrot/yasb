## Behavior and decisions

Metadata-read validity is now separate from displayed metadata continuity. Every observed metadata notification or CLOSED event allocates a backend-wide monotonic revision and immediately invalidates seeking. Only a successful current read publishes a valid seek revision. Pending/failed reads retain existing presentation but cannot seek; artwork-only failure still permits a successful text read. Timeline/playback events cannot revalidate an unresolved read. Revisions survive session removal/readdition and source retirement; presentation `_same_track` and `track_identity` policies remain unchanged.

V2 captures session/revision at gesture start, cancels on invalidation outside the content-update shortcut, and forwards the revision to the backend dispatch gate. The compatibility adapter exposes validity without hiding retained legacy progress. Both legacy sliders capture origin/session/revision/duration, invalidate before disabling/interpolation, retire synchronously before tracked submission, and reject hidden/closing/replaced slider callbacks. The adapter still returns an awaitable backend Task. Foreign old press/release cannot cancel the current slider gesture.

Return/keypad Enter now explicitly activates InfoButton once, ignoring repeat/disabled activation; Space retains normal Qt behavior. Player-menu updates reuse unchanged actions and preserve highlighted session ID during necessary rebuilds. Actions resolve current model IDs. Parent close immediately retires its owned menu, including direct hide. No upstream PopupWidget rewrite.
