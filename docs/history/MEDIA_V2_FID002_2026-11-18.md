  amplitude and keeping its phase alive. Cancellation/reset now stops only the
  position animation; hidden teardown still stops all owned presentation work.

  the incoming path; an actual pixel oracle reproduces and verifies the repair.
- Reopen now resets stale hover scale/opacity.

  concealment. Partial-intro close/reopen has a regression.

  distinguishes a selected incoming control from an outgoing collapsed control.
- Header width testing reproduced moving tab targets with long status labels.
  Reserving the EQ allocation keeps targets stationary across pages.

Failed trials and exact outputs remain in `.git/fidelity-motion/`. Tests were
not weakened or skipped to hide failures. Type errors were corrected, including
Qt override parameter names, explicit tuple indexing and typed access to the
existing dynamic animation map. Independent final source review found no new
