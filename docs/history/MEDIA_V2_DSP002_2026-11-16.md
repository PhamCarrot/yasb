## Implemented

- Independent stereo-linked mean-square compressor:10ms detector, no makeup,
  reference Balanced/Night threshold/ratio/knee/attack/release constants.
- Sample-peak limiter: nominal5ms window, actual`floor(.005fs)-1` delay,
 50ms release, linked gain and final channel clamps. Historical gain requirements
  retain each sample's original ceiling when modes change. Dynamics ceiling−1dBFS;
  adaptive-only safety ceiling−0.1dBFS. No limiter when both modes are off.
- Real adaptive EQ:16384-point periodic-Hann stereo-power FFT/8192hop,
 27third-octave observations,17Q2half-octave filters, weighted/ridge/smooth fitting
  with two residual refinements, asymmetric shaping/bass preference, admitted
  four-second warmup, K-weighted makeup, quarter-second slew. Makeup slews linear
  amplitude each sample. Manual curve remains saved but is neutralized while
  adaptive processing is enabled. Disable fades neutral; reenable resets learning.
- Causal sample boundaries and persistent32-sample gain phase deliberately avoid
  reference block-partition artifacts. Useful-band/broadband energy rejection
  prevents DC Hann leakage from steering learning; low tones and DC+signal remain
  eligible. The pinned frozen relative-gate history is retained/documented: a
  >10dB sustained drop can remain excluded until louder input or reset.
- Immediate zero-delay bypass freezes all DSP history. Protocolv2 distinguishes
  suspended, supported callback, unsupported rate and bypass. Status168bytes adds
  latency/flags/dynamics/adaptive counts/gains/makeup. Settled revision means the
  manual/stereo ramp completed, not adaptive or envelope convergence/audibility.
- Host-visible initialDelay updates on the control side. IO-changed notification
  occurs outside the mutex, with a reentrant host-query regression. Existing host
  stop-and-drain contract remains required before reset/destruction. Large FFT
  storage resets in place, avoiding a large stack temporary.

Native [README](../../src/core/widgets/services/media/native/README.md) records
scope/provenance. This is independent MIT implementation from mathematical
contracts, not copied/translated AGPL engine code. Existing default widget/APO
configuration behavior is unchanged. Native DLL remains optional/offline, not
loaded, installed or included in ordinary YASB packaging yet.
